# PRD: Edge + 个人云端自动切片

## 1. 背景

当前 AI 自动切片以 `PostProcessTaskType.aiClipAnalysis`、`ClipSegment` 和 `AutoClipService` 为核心，目标偏向“下载完成后生成候选片段并自动切文件”。这个方向不足以解决实际问题：

- 候选片段缺少完整媒体信息基础，无法解释为什么该切这里。
- 本地切完后缺少资产化浏览、检索和长期管理能力。
- 云端模型只是远程 JSON 分析端点，不具备个人云端部署、上传、云端切片和结果同步。
- 长视频、音频、跨设备素材管理和个人知识库场景无法成立。

新版目标是把下载结果转化为可本地管理、可云端重算、可检索、可复用的媒体资产。

## 2. 产品目标

- 用户下载视频或音频后，本地自动生成结构化媒体资产。
- 用户可以在本地浏览、搜索、预览、调整和导出切片。
- 用户可以把分析包、已切片文件、指定片段或原片上传到个人云端。
- 个人云端可以独立执行切片任务，并把结果同步回本地。
- 用户可以通过私有云端远程浏览切片结果，不依赖公共 SaaS。

## 3. 用户场景

### 3.1 本地切片与浏览

用户下载一个视频后，应用自动分析媒体，提取字幕、章节、镜头边界、候选切片、关键词和向量数据。用户在本地切片库里搜索、预览并导出片段。

### 3.2 云端重切

用户在本地看到候选片段后，选择“上传到个人云端切片”。默认只上传分析包和片段范围；如果需要云端重新精剪，用户再显式授权上传原片或媒体可访问地址。

### 3.3 远程浏览

用户在 NAS/VPS 上部署个人云端后，可以在浏览器中查看媒体列表、切片任务、切片文件和日志，适合长任务离线运行。

### 3.4 跨设备素材库

用户在多台设备上下载或处理素材，云端保存统一的媒体资产索引和切片结果。本地设备可拉取云端结果，但本地数据仍是可信源。

## 4. 功能需求

### 4.1 媒体资产生成

- 下载完成后创建 `MediaAsset`。
- 记录源 URL、标题、媒体路径、文件指纹、时长、大小、格式、音视频流、缩略图、字幕、章节和下载任务 ID。
- 为音频和视频都生成统一资产，不把音频当作视频功能的次要路径。

### 4.2 本地分析

- 本地提取 ffprobe 元数据。
- 本地解析已有字幕和下载信息。
- 本地可选执行 ASR、VAD、场景检测、关键帧抽样、视觉对象识别和 embedding。
- 本地分析结果保存为结构化 manifest，供本地浏览和云端任务复用。

### 4.3 本地切片

- 支持基于候选片段、用户自定义时间段、章节、字幕话题和场景边界切片。
- 支持 FFmpeg 切片进度、取消、重试和失败原因。
- 切片结果必须记录为 `ClipExportRecord`，并关联原媒体、候选片段和实际输出路径。

### 4.4 本地浏览

- Clips 页升级为本地媒体库。
- 支持媒体列表、切片列表、时间线、搜索、标签、转写片段、切片状态和导出记录。
- 支持打开本地切片目录和预览切片文件。

### 4.5 上传到个人云端

- 支持上传分析包、已切片文件、指定片段范围和原片。
- 原片上传默认关闭，必须在任务级确认。
- 支持大文件分块、断点续传、SHA256 校验、取消和重试。
- 上传前显示文件大小、上传内容、隐私范围和云端任务类型。

### 4.6 云端切片

- 云端接收媒体任务后进入队列。
- 云端 Worker 使用 FFmpeg 和配置的 AI 能力执行分析、切片和导出。
- 云端返回结构化结果、切片文件下载地址、日志、工具版本和错误列表。

### 4.7 个人云端配置

- 设置页新增个人云端配置。
- 字段包括服务地址、设备名、Pairing Token、访问 Token、默认上传策略、最大并发、同步开关。
- 提供连接测试和重新配对。

## 5. 隐私与安全边界

- 不默认上传原片。
- 不上传 Cookie、下载凭证、API Key 或个人账号数据。
- 云端为个人私有部署，不进入公共 SaaS 模型。
- 服务端 Token、JWT Secret、对象存储目录必须由部署者控制。
- 所有上传任务都记录用户选择的上传范围。

## 6. MVP 边界

MVP 必须完成：

- 本地媒体资产生成。
- 本地候选切片和 FFmpeg 导出。
- 本地媒体库浏览。
- Docker 自托管云端最小服务。
- 本地上传分析包和已切片文件。
- 云端任务列表、结果回传和日志查看。

MVP 不做：

- 多租户账号体系。
- 公共 SaaS 托管。
- 自动原片上传。
- 云端复杂协同编辑。
- 移动端客户端。

## 7. 验收标准

- 下载完成后能生成 `MediaAsset` 和本地分析 manifest。
- 本地切片成功后，切片库能展示并打开结果。
- 设置页能配置个人云端并完成连接测试。
- 本地能上传分析包到云端并创建云端任务。
- 云端 Docker Compose 可以启动 API 和 Worker。
- 云端切片任务状态能同步回桌面端。
- 原片上传必须出现明确确认，不允许静默上传。

## 8. 下一步

- 完成云端 result manifest 到本地媒体库的自动导入。
- 将云端 Worker 从同步触发升级为后台队列，支持运行中取消、重试和日志查看。
- 把轻量 keyword hash 向量替换为可插拔真实 embedding provider。
- 补齐 Docker 镜像 FFmpeg 依赖、部署冒烟脚本和个人云端 Web UI。
